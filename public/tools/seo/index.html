Install MiCirql Chrome extension

Install from this website to capture and audit pages in your own browser. Chrome requires you to approve the installation.

Download MiCirql extension ZIP

If the ZIP download returns HTTP 404, use the GitHub source ZIP instead. Extract it and select the nested extension folder when using Load unpacked in Chrome.

  1. Download the ZIP and extract it to a permanent folder.
  2. In Chrome, open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Return to this page and reload. The connection status above should say Chrome extension connected.

Updating an existing unpacked installation: download the newest ZIP, extract it into the same permanent extension folder (replace the old files), open chrome://extensions, click Reload on MiCirql Tools, then refresh this page. Do not select a new folder unless you intend to install a second copy.

For HTTP response checks you need extension 0.3.13 or newer with HTTP evidence support. The connection badge above displays the detected version and whether HTTP evidence is supported. A supported version does not guarantee HTTP evidence is observed for every page; check audit coverage.

Chrome cannot install an unpacked extension automatically. This ZIP is provided directly by MiCirql; Chrome Web Store installation will require separate publication. Demo audits work without the extension.

Type your website and press Enter or select Scan website pages. MiCirql will discover and check its accessible pages automatically.

Current coverage limit: up to 60 discoverable pages per scan. Sites with more pages are only partially covered; missing, inaccessible or unvisited pages are reported as limitations. This is an HTML audit, not a complete technical crawl.

Choose pages to include, up to the selected batch size.

After scanning, select Save PDF audit report, then choose Save as PDF in the browser print window. No website changes are made.
